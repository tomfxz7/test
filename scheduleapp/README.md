# スケジューリングアプリ

`schedule.jsx` は React と `lucide-react` を利用するアプリです。既存の React 実行環境に読み込んで使用します。

## 進捗ページ

ボードの「進捗ページに表示」をチェックしたタスクを、未着手・着手中ボードで管理します。未着手の＋からの追加も、カレンダーや一覧と共有されます。着手時の設定でやるべきことを追加できます。チェックを外してもタスクと履歴は残ります。

### カードとトークの範囲

- タスクカードをクリックすると、タスク全体のトークを表示します。未着手・完了済みのタスクも選択できます。
- やるべきことカードをクリックすると、そのやるべきことと、所属するすべての小さいタスクのトークを表示します。
- 小さいタスクカードをクリックすると、その項目だけのトークを表示します。小さいタスクは常時表示し、展開・折りたたみは行いません。クリック・ダブルクリック・Enterによる引用返信は行いません。
- 引用返信はトーク内の「返信」ボタンで開始します。相手待ちは独立したカードを作らず、対象の小さいタスク・やるべきことを緑色にします。内容はその範囲のトークに残します。
- 上部の検索・絞り込みも利用できます。タスクのタイトルをクリックすると全体に戻ります。通常の入力では、選択したやるべきこと・小さいタスクに続けて記録できます。

### 色と完了

| 状態 | 色 |
| --- | --- |
| 完了・クローズ | 青 |
| 期限超過 | 赤 |
| 相手待ち | 緑 |
| 関連するタスクの完了待ち | 黄色 |
| 進行可能・進捗中 | 紫 |
| ただのコメント | グレー |

カードは完了、関連するタスクの完了待ち、期限超過、相手待ち、進行可能の順に判定します。完了した小さいタスクの進捗トークと引用枠はすべて青色になります。やるべきことを完了すると、その範囲の進捗トークが青色になり、案件をクローズすると案件全体の進捗トークが青色になります。「ただのコメント」は状態を変えず、完了後もグレーです。表示色を変更しても、過去のコメントの投稿日時や当時の状態は書き換えません。

小さいタスクを完了すると、カードを青色で残し、最初の追加トークだけを削除します。完了したカードをクリックすると、その小さいタスクの完了済みトークを確認できます。ほかのトークと保存済みの引用は保持します。新規送信・引用返信・既存トークの編集保存から完了できます。完了だけなら本文は不要です。古いバックアップでトークだけが完了になっていた不整合も読み込み時に補正します。完了情報はコメントとは別に保存し、コメントを削除しても完了状態は失われません。

やるべきことに未完了の小さいタスクや、完了を待つ関連先が残っていない場合、カードに「やるべきことを完了」ボタンを表示します。押すとそのやるべきことを完了し、完了記録を残します。小さいタスクの完了だけで、やるべきことや案件全体を自動完了にはしません。

### 相手待ちステータス一覧

タスク・やるべきこと・小さいタスクのカードにある「相手待ち一覧」ボタンで、現在相手待ちの項目と、各項目の直近の相手待ちトークをポップアップで確認できます。ボタンの件数は相手待ちの項目数です。タスクカードは案件全体、やるべきことカードはその配下の小さいタスクを含む範囲、小さいタスクカードはその項目だけを表示します。

完了済み・相手待ち解除済みの項目は含めません。トークがない相手待ちは「内容はまだ記録されていません」と表示します。画像・リンクも確認でき、ポップアップを開閉してもトークの選択範囲や保存データは変わりません。

### タスク待ちの関連付け

カードの「タスク待ちを設定」から、完了を待つ項目を複数選択できます。

- 小さいタスクは、同じやるべきことの中の別の小さいタスク、または同じ案件内の別のやるべきことを選択できます。自分自身や自分の親は選べません。
- やるべきことは、同じ案件内の別のやるべきことを選択できます。
- 未完了の関連先が1件でもあれば黄色で表示し、完了操作を無効にします。すべて完了すると自動で待ち状態を解除し、通常は紫色の進行可能に戻ります。期限超過や別の相手待ちがある場合は、その状態の色になります。
- 循環する関連付けは保存できません。関連先が未完了のまま削除された場合は待ち状態を維持し、設定画面で削除された関連先を外せます。
- 関連付けはJSONバックアップにも保存されます。

### 画像・リンク

トークに画像とリンクを添付できます。画像はファイル選択・貼り付けに対応し、クリックで拡大できます。PNG・JPEG・GIF・WebP・AVIF形式、1枚10MBまで対応します。リンクは表示名を付けて添付でき、HTTP/HTTPSのリンクを別タブで開きます。本文なしの添付だけの送信も可能です。

編集中は添付を追加・削除でき、キャンセルすると保存前の内容を保持します。引用は添付の送信時点の内容をコピーするため、引用元を編集・削除しても添付は引用内に残ります。画像は外部アップロードせずIndexedDBに保存し、JSONバックアップにも含めます。週報には画像名とリンクを含め、画像のバイナリデータは含めません。

### 記録・追加・編集

- Ctrl+Enter または「送信」で記録します。「相手待ち」「完了」は選択した対象に反映し、関連するやるべきことを選んでいない相手待ちはタスク全体が対象です。
- 「やるべきことの追加」は本文から新しいやるべきことを作ります。期限の空欄時は親タスクの期限を使います。通常の追加では自動のトークを残しません。
- 「小さいタスクの追加」は関連するやるべきことを1つ選び、本文をその中に追加します。小さいタスク自体の期限入力は不要です。最初の追加トークを1件残します。
- 引用返信中も次の作業を追加できます。「完了」は返信元に適用し、新しい作業は未完了で作成します。返信の引用は保持します。
- 編集は元の投稿日時と引用を保持します。本文だけの編集で、後から変更された状態を戻しません。「完了」を保存した小さいタスクは、一覧と関連トークにも反映します。
- トークの削除はほかのトークや保存済みの引用を消しません。ただし、未完了の小さいタスクの追加トークを削除した場合は、その小さいタスクも削除します。カードのごみ箱からの削除でも、過去のトークと引用は残します。
- 設定から名前・期限・やるべきことを変更できます。期限変更で理由を入力した場合だけ、変更日時・変更前後の日付・理由を記録します。不要な過去の自動ログは表示せず、保存済みデータは保持します。

進捗情報は既存の IndexedDB のタスク内に保存され、JSON のエクスポート・インポートにも含まれます。

トーク表示に失敗してもボード全体は消さず、別のカードに切り替えられます。「エラーの詳細」から表示内容を確認でき、保存済みデータは変更しません。過去データの画像・リンク欄がnullなどの場合も、添付なしとして表示します。

## 週報用レポート

インポート／エクスポートの隣の「レポート作成」から、対象タスクと開始日・終了日を選んで UTF-8 のテキストファイルをダウンロードできます。初期期間は7日前から今日まで（両日を含む）です。進捗管理中のタスクを初期選択し、検索・一括選択・解除で対象を変更できます。未完了タスクと、指定期間内に完了したタスクだけを選べます。期間外に完了したタスクは表示・出力しません。定期予定の未完了分は期間内の回を表示し、完了分は予定日ではなく完了日時で判定します。

レポートには Copilot 向けの週報作成指示、選択タスクの情報、やるべきこと・小さいタスク、期間内の進捗・完了・相手待ち・理由付き期限変更、引用を記載します。日付範囲はブラウザーの現地時刻で両日を含み、コメントの投稿日時で抽出します。現在の状態や日時のない結果メモ、期間外の引用は参考情報として分け、期間内の実績と混同しない形式にしています。画像データは出力せず、レポート作成によってタスクや履歴が変更されることもありません。

完了操作でタスク全体の `completedAt` を保存し、完了を取り消すと解除します。完了状態のままメモや期限を変更しても完了日時は変わりません。過去の完了日時未記録タスクは期限日を完了日として扱い、その旨をレポートに記載します。完了日時・期限日の両方がないものだけを対象から除外します。完了日時はJSONバックアップにも保持されます。

## ブラウザー回帰テスト

リポジトリのルートで実行します。Python 3.9 以上、Playwright と Chromium が必要です。

```sh
python3 -m pip install playwright==1.62.0
# システムの chromium がない場合
python3 -m playwright install chromium
python3 scheduleapp/tests/test_progress.py
```

テストは固定バージョンの React・ReactDOM・Babel・lucide-react・Tailwind の公式配布物を `cdn.jsdelivr.net` から取得し、実際の JSX をブラウザーで実行します。npm の導入やアプリのビルドは不要です。各テストで IndexedDB を分離し、ボードとの同期、ドラッグ操作、コメント・状態・期限変更履歴、不要な自動コメントの抑制、期限変更理由の記録、コメントの色分け、引用返信と相手待ちコメントの置換、コメント編集とチェック項目の更新、永続化とエクスポート、キャンセル時の保護、低い画面とモバイル幅での送信操作を検証します。
