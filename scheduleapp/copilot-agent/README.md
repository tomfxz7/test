# Copilotエージェントの設定

[設定一式（ZIP）をダウンロード](copilot-summary-agent.zip)

個別ファイル：[指示文（コピー用）](instructions.txt) ／ [ナレッジ（Word）](knowledge.docx) ／ [アップロード用スキルZIP](task-talk-summary-skill.zip) ／ [SKILL.md](skills/task-talk-summary/SKILL.md) ／ [任意の手順定義書（Word）](summary-procedure.docx)

GitHubからファイルを取得するときは、ダウンロードボタンまたは「Raw」を使います。SKILL.md は先頭の `---` から始まるYAMLを含め、ファイル全体を保存してください。

## 名前と説明
- 名前：タスクトーク要約アシスタント
- 説明：送信されたWordから、現状・決定事項・残件・次の行動を、画像・表・URLも活用したMarkdownにまとめます。

## 添付画像の作成画面に設定する内容
1. 「指示」：instructions.md または instructions.txt の全文を貼り付けます。
2. 「ナレッジ」：「ナレッジの追加」またはファイルのドロップで knowledge.docx を追加します。これはアプリの用語とデータの読み方を説明する固定資料です。
3. 「スキル」：[アップロード用スキルZIP](task-talk-summary-skill.zip) をそのまま選びます。ZIP直下に `SKILL.md` が1つ入っています。[SKILL.md](skills/task-talk-summary/SKILL.md) の単体アップロードにも対応します。設定一式ZIPをダウンロードした場合は、中の `task-talk-summary-skill.zip` を取り出してアップロードしてください。名前・説明・指示を入力する画面では、SKILL.md の `name`、`description`、その下の本文を各欄へ転記します。
4. 設定を保存し、下記の手順で試します。

スキル欄の設定形式は利用するCopilot環境で確認してください。「指示」だけで使う場合も、画像の配置と出典のルールは instructions.txt に含まれています。

## 毎回の使い方
1. アプリで対象の大タスクを確認します。
2. 大タスクタイルの右クリックメニューで「AI要約用Wordを出力」を押します。前回の要約と現在の全体記録が出力されます。画面の検索・絞り込みには限定されません。
3. 作成したエージェントの会話へWordを添付して送信します。メッセージ本文は空でもよく、「要約して」の追加入力は不要です。ファイルを置くだけではなく、添付メッセージを送信します。
4. エージェントが返したMarkdownの本文をコピーします。
5. 同じ大タスクタイルの右クリックメニューで「AI要約を入力」を押し、最初のAI_BATCH付き見出しから末尾の参考資料まで全体を空の入力欄へ貼り付け、「要約を保存」を押します。全体と各やるべきことに自動で振り分けられます。
6. 「AI要約」または「最新の要約結果を表示」で最新版を表示します。次に保存した内容で全体と各やるべきことの最新要約をまとめて置き換えます。要約がない画面の出力・入力ボタンも、同じ大タスク全体に対応します。

## 試すときの確認点
- Wordを添付して送信するだけで、形式や作成可否の確認なしに要約が返る。
- 出力全体がコードブロックで囲まれておらず、見出し・表・URLが貼り付け先でも読める。
- 大タスク全体と一部のやるべきことの資料を混同しない。
- 引用元のリンクは回答末尾の「参考資料」に一度だけ載り、同じURLは重複しない。
- スクリーンショットの依頼文を添えなくても、取得・再掲できる重要な画像が対応する説明の直後に表示され、「参考資料」には出典情報だけが載る。
- 0件の資料や不明な担当・期限について事実を作らない。

個別案件のWordは毎回の会話に添付します。共通知識として固定する必要はありません。

## 更新時の注意
以前のエージェントを使用している場合は「指示」を最新版に置き換え、「ナレッジ」の knowledge.docx も更新してください。旧プロンプトの回答には振り分けIDがないため、新しい一括入力では保存できません。
全体だけ・一部の項目だけをコピーせず、Wordに指定されたID付き見出しを含めた回答全体を貼り付けます。ID不足・重複・別タスク・別の出力回の結果がある場合、アプリは部分保存せずエラーを表示します。
Word出力後にやるべきことを追加・削除・非表示にした場合は、Wordを再出力して要約し直します。出力後に新しいトークが追加された場合は、今回の要約に含まれたものと誤認せず、次回のWordで追加記録として比較できます。

## 全体要約の編集方針
全体要約はやるべきこと別の章立てにせず、案件を横断した論点・判断テーマごとに整理する指示に更新しています。結論・進捗・決定事項・未確定事項・優先順位・重要ポイント・ボールの所在・待ち条件・決定条件・今後の進め方と日程感をつなげて示します。項目別要約は自動振り分け用の別枠として維持しています。
既存エージェントでは instructions.txt の全文を「指示」に置き換え、knowledge.docx と、登録している場合は summary-procedure.docx も更新してください。ID付き見出しの形式は変わらないため、アプリの振り分け機能との互換性は維持されます。

## 過去のAI要約の影響を避けて再生成する
大タスクの右クリックから「AI要約用Wordを出力（前回要約なし）」を選びます。前回のAI要約や比較情報を含めず、元のトークと現在の状態・元資料だけを出力します。ファイル名にも「前回要約なし」が付きます。保存済みの要約は削除しません。通常モードの出力ボタンもそのまま使えます。
両方のWordに、全体要約はやるべきことごとではなく横断的に内容を整理することを明記しています。前回要約なしの場合は、過去の会話内のAI回答も参照しないよう指示しています。独立してやり直す場合は、必要に応じてエージェントの新しい会話へこのWordを送信できます。
回答の一括貼り付け・IDによる自動振り分けはどちらのモードでも同じです。直近に出力したWordに対応する回答を貼り付けてください。

## 簡潔な要約とPowerPointの参照
追加ルールを本文に統合し、結論を先に短く示し、比較・残件・担当・期限は表を優先、判断理由だけ短い文章で補う方針に整理しました。「対応優先順序」に表現を統一し、資料で決定済みの順序と要約上の整理・提案を区別します。強調はアプリに貼り付けて表示できる太字・意味付き記号を使います。

元トークやカードの参照先がPowerPointなら、参照できるスライドを開き、判断に役立つ図表は追加の依頼を待たずにスクリーンショットや画像書き出しを試します。Word内や同時添付の画像も対象です。画像は該当する全体要約または項目別要約で「説明 → 実画像 → 短いキャプション」の順に配置します。キャプションには必要に応じて資料番号・スライド番号を添えます。参照リンクは回答末尾の「参考資料」に集約します。アプリに貼り付けて保存すると、共通の参考資料は全体要約の末尾に表示されます。

**指示文だけではPowerPointの閲覧機能やアクセス権は追加されません。** 使用するCopilot環境で対象資料を読める機能・アクセス権が必要です。リンクが開けない場合はPowerPoint本体または該当スライド画像をWordと一緒に添付してください。アプリのWord出力はリンクと閲覧の依頼を含み、PowerPoint本体を自動取得・添付するものではありません。Copilotが画像を別ファイルで返した場合は、回答を貼り付けた後、画像ファイルも要約の該当箇所へ貼り付けてください。

既存エージェントの「指示」を instructions.txt に置き換え、knowledge.docx と、使用している場合は summary-procedure.docx も更新してください。アプリから出すWordの依頼文にも同じ方針を反映しています。通常モードと前回要約なしモード、IDによる一括振り分けは維持しています。
