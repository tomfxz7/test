# Copilotエージェントの設定

[設定一式（ZIP）をダウンロード](copilot-summary-agent.zip)

個別ファイル：[指示文（コピー用）](instructions.txt) ／ [ナレッジ（Word）](knowledge.docx) ／ [任意の手順定義書（Word）](summary-procedure.docx)

GitHubでWordやZIPを開いた場合は、ファイル画面のダウンロードボタンまたは「View raw」から取得できます。

## 名前と説明
- 名前：タスクトーク要約アシスタント
- 説明：送信されたWordから、現状・決定事項・残件・次の行動を、画像・表・URLも活用したMarkdownにまとめます。

## 添付画像の作成画面に設定する内容
1. 「指示」：instructions.md または instructions.txt の全文を貼り付けます。
2. 「ナレッジ」：「ナレッジの追加」またはファイルのドロップで knowledge.docx を追加します。これはアプリの用語とデータの読み方を説明する固定資料です。
3. 「スキル」：今回の文章要約では追加不要です。任意の手順書 summary-procedure.docx はナレッジへ追加できます。スキル欄で指示型・プロンプト型の設定が選べる場合は、summary-procedure.md の名前・説明・入力・処理・出力をその設定に転記できます。この定義書は自動インポート用のスキルパッケージではありません。
4. 設定を保存し、下記の手順で試します。

## 毎回の使い方
1. アプリで対象の大タスク・やるべきこと・小さいタスク・その他のトークを選びます。
2. 必要ならトークを絞り込み、「AI要約用Wordを出力」を押します。
3. 作成したエージェントの会話へWordを添付して送信します。メッセージ本文は空でもよく、「要約して」の追加入力は不要です。ファイルを置くだけではなく、添付メッセージを送信します。
4. エージェントが返したMarkdownの本文をコピーします。
5. アプリの同じトーク範囲で「AI要約を入力」を押し、空の入力欄に貼り付けて「要約を保存」を押します。
6. 「AI要約」または「最新の要約結果を表示」で最新版を表示します。次に保存した内容で、その範囲の要約を置き換えます。

## 試すときの確認点
- Wordを添付して送信するだけで、形式や作成可否の確認なしに要約が返る。
- 出力全体がコードブロックで囲まれておらず、見出し・表・URLが貼り付け先でも読める。
- 大タスク全体と一部のやるべきことの資料を混同しない。
- 画像名・実在URLは残し、Word内画像に架空の再掲URLを作らない。
- 0件の資料や不明な担当・期限について事実を作らない。

個別案件のWordは毎回の会話に添付します。共通知識として固定する必要はありません。
