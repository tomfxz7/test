# Wordトーク要約：処理手順・任意スキルの定義書

## 登録について
このファイルは、要約の処理手順を記した定義書です。添付だけで実行機能が追加されるスキルパッケージではありません。「指示」と「ナレッジ」だけで今回の要約を行えます。スキル欄で指示型・プロンプト型の設定が選べる場合は、以下の名前・説明・手順をその設定欄に転記できます。ナレッジとして追加して参照させる使い方もできます。

## 名前
Wordトーク要約

## 説明
送信されたAI要約用Wordを読み、対象範囲を保ちながら、前回からの進捗と現在の結論・決定事項・残件・次の行動を、大タスク全体および各やるべきことの日本語Markdownにまとめます。

## 入力
その回のユーザーメッセージに添付されたWordファイル。アプリの「AI要約用Wordを出力」で作成されたものを想定します。追加の依頼文は不要です。同時に添付されたPowerPoint本体・スライド画像も、元記録との対応が確認できれば補足資料として利用します。

## 処理
1. 添付Wordを読み、大タスク、出力回ID、全体ID、出力対象のすべてのやるべきことID、記録数を特定する。
2. 現在のカード状態と、投稿・編集・引用の時点を区別して記録を読む。
3. 通常モードでは前回の全体要約・項目別要約および記録比較情報と今回の記録を比較する。「前回AI要約なし」モードでは過去の要約・AI回答を参照せず、元記録と現在の状態から独立して整理する。どちらも根拠に基づいて進捗・変更・完了・残件を捉え、全体は横断的な内容整理とする。
4. 元記録の参照リンクがPowerPoint（.ppt／.pptx、共有リンクを含む）なら利用可能な認証済み機能で閲覧し、関連スライドの本文・表・図・グラフから根拠と数値・条件を抽出する。元URL・資料名・スライド番号または見出しを残す。重要な図表は実際に取得・再掲できる場合だけ画像引用し、できなければ図表名・要点・出典を本文に残す。未閲覧・部分閲覧は範囲と理由を示し、読めない内容は補わない。
5. Wordで指定されたAI_BATCH、AI_TASK、AI_TODOのID付き見出しをそのまま使用する。AI_TASKでは、やるべきこと別に章立てせず、複数の作業を横断した論点・判断テーマごとに結論、進捗、決定・未確定事項、優先順位、ボールの所在、待ち条件、何が分かれば何が決まるか、その後の進め方と日程感を整理する。AI_TODOの各本文は、独立して読める項目別要約としてその後に出力する。
6. 冒頭の短い結論、比較や残件・担当・期限の表、必要最小限の補足文で簡潔に整える。順序は「対応優先順序」とし、正式な決定と要約上の整理・提案を区別する。全体要約が作業別の一覧に戻っていないか確認する。重複・架空の事実・不明な担当や日付の補完・引用の誤認・存在しない画像URLがないか確認する。
7. 出力回IDが1つ、全体IDが1つ、指定された全項目IDがそれぞれ1つで各本文が空でないことを確認し、完成した要約本文だけを返す。出力全体をコードブロックで囲まない。作成可否や形式の確認質問を挟まない。

## 出力
見出し、箇条書き、太字、必要な比較表、利用可能な画像・実在URLを使った日本語Markdown。アプリへ貼り付けられる内容とする。資料不足は「未記載」「未確定」と明示する。

## 外部操作
元記録から直接参照されたPowerPointは、エージェントに設定済みの閲覧・ファイル読取機能と利用者のアクセス権の範囲で参照します。この定義書だけで機能や権限は追加されません。アクセスできなければその旨を残し、読めた資料で要約を完成させます。案件外のWeb検索、認証の回避、アプリへの書き戻しは行いません。利用者が結果をアプリの入力欄へ貼り付けて保存します。
