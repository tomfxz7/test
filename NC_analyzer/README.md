# WAVのNC解析 (`analysis.jsx`)

React と `lucide-react` のあるホストから、`analysis.jsx` の既定エクスポートを描画します。FFT・NC判定・ZIP処理はコンポーネント内にあり、JSZip は不要です。`index.html` は従来の測定データ読込・レポート用アプリです。

## 画面の使い方

- **左：読み込みと設定** — NCAの読み込み・保存、校正音WAV、解析対象WAV、グループ、再生音量、スペクトログラムの感度・時間軸拡大・高さ、グラフと出力の設定。
- **中央：解析ファイル一覧** — Excel風の表とスペクトログラムを切り替えます。セルをドラッグして矩形範囲を選び、Shiftで拡張、Ctrl / ⌘で追加・解除できます。行番号やチェックボックスでも行を選択できます。ドラッグハンドル・上下ボタン・見出しのソートで順序を変更します。検索とグループの絞り込みは一覧の表示だけに作用し、「全選択」は表示中の行が対象です。
- **右：解析結果** — 一覧と同じ順の個別グラフ、またはグループ別の重ね合わせグラフを表示します。比較グループは一覧で最初に現れる順、その中の測定値・凡例も一覧順です。「表示」をオフにした範囲はグラフから隠れますが、解析結果と出力には残ります。

`index.html` と同様に、グループはファイル読み込みとは独立して作成します。新規WAVは常に先頭グループにまとめて読み込みます。グループを新規作成しても読み込み先は切り替わりません。

表で対象セルをドラッグ選択した後、グループ列をダブルクリックして選ぶか、右クリックのメニューから、選択範囲に含まれる行へ一括割り当てします。表示名もダブルクリック、EnterまたはF2で編集でき、Escapeで変更を取り消します。名前の編集中はEnter / Tabで次の行へ進めます。ソート・上下移動後も選択対象は同じファイルに保ちます。

Ctrl+C / Ctrl+V（Macは⌘）でTSV形式の表をコピー・貼り付けできます。名前とグループだけを編集し、元ファイル名・NC判定値は書き換えません。貼り付けで新しいグループ名が現れた場合はグループを追加します。Deleteは選択した表示名を空欄にし、グループは先頭へ戻します。ファイル自体の削除は「削除」ボタンで行います。サイドバーの入力中に表のショートカットが作用することはありません。

WAVの読み込みと同時に自動解析します。校正音や基準レベルを変更すると自動で校正し、全ファイルの結果を更新します。未校正の場合は従来と同じオフセット100で相対的な参考値を算出します。解析・校正ボタンの操作は不要です。

スペクトログラムの黄色い端をドラッグするか、IN / OUT を秒単位で入力して範囲を選びます。範囲の複製も可能です。範囲変更では、その範囲だけを自動で再解析します。他のファイルの完了済み・実行中の解析は再利用します。連続する変更は40msでまとめ、古い条件の計算は中止して最新の範囲を採用します。長いWAVのFFT中も入力を受け付けます。名前・グループ・並び順や表示の変更では再解析しません。更新中のグラフは薄く表示し、最新の結果が揃うまで出力を待機します。

再生音量とスペクトログラム感度は、全ファイルまたは指定した範囲だけに適用できます。時間軸の拡大・高さ・最低／最高周波数は全スペクトログラム共通です。周波数は初期値100〜1000 Hzで、音源のナイキスト周波数までの範囲を対数表示します。これらはNCAにも保存します。再生音量は100倍（10000%）まで設定でき、個別・ZIPの切り抜きWAVにも同じ倍率を反映します。PCMの上限を超えたサンプルはクリップします。音量と表示設定はNC解析値には影響しません。NCAの元音源は増幅せず保持します。従来どおり、解析は第1チャンネル、切り抜きWAVの出力は全チャンネルが対象です。

## 暗騒音

表とスペクトログラムの「暗騒音」チェックボックスで、解析範囲を暗騒音として指定します。グループの所属とは別の設定です。初期設定は「すべてのグループで共通の暗騒音を使用」で、全体で1件だけを共通使用します。チェックを外すと各グループに1件ずつ指定できます。別の範囲をチェックすると、その共通／グループの指定を置き換えます。

指定した範囲の、校正済み・未増幅のオクターブ帯域値を、各グループと個別結果のグラフに灰色の破線で重ねて表示します。暗騒音を差し引く処理は行わず、測定値とNC値は変えません。暗騒音の範囲変更では、その音源だけを再解析し、参照先のグラフを更新します。指定解除・グループ変更・削除でも参照先を更新します。グループ別の暗騒音を別グループへ移すと指定を解除します。

NCAには暗騒音の指定と元の解析結果を保存します。追加読込では現在の共通指定を維持し、取り込んだグループ別指定は移し替えたグループに復元します。`index.html` 向けJSONには暗騒音を各グループの比較データ（凡例に「暗騒音」と表示）として含めます。読込先の全体設定が差し引きモードでも測定値が変わらない形式です。CSVは元の測定値、切り抜きWAVは従来どおり音量倍率を適用した波形を出力します。

## 保存・互換性

**NCA** は元のWAV（同じ音源は一度だけ格納）、校正音、範囲・順序、グループ、解析結果、表示設定を含むZIPです。従来の `nc-analyzer-project` バージョン1に項目を追加しており、旧NCAも読み込めます。

- 読み込みの「上書き」は現在のワークスペースを置き換えます。「追加」は現在の校正・出力設定・保存先を維持し、同名のグループには連番を付けます。校正条件の異なる保存済み結果は流用せず、取り込み後に自動で再解析します。読み込みに失敗した場合、現在の内容を保持します。
- 「NCA出力」はダウンロード、「別名で保存」は保存先の選択、「上書き保存」は設定済みのファイルへの保存です。保存先未設定の場合は選択画面を開きます。File System Access APIに対応する安全なコンテキストでは、上書きモードでNCAを開いた際もそのファイルを保存先にできます。
- 保存先の保持は現在のページを開いている間だけです。再読み込み後はNCAを開き直してください。直接保存に非対応のブラウザーではダウンロードに切り替え、その旨を表示します。
- 「index.html 用プロジェクト出力」は、解析済みの範囲を `index.html` の「プロジェクト読込」（またはワークスペース読込）で使えるJSONにします。表示名・順序・グループ・表示状態と8帯域の測定値を含みます。未解析の範囲と元WAVは含みません。
- CSV・切り抜きWAVの個別出力、一括ZIP出力も利用できます。ZIP内の同名ファイルは連番で保存します。

## ブラウザー回帰テスト

リポジトリのルートで実行します。Python、Playwright 1.62.0、Chromium が必要です。

```sh
python3 -m pip install playwright==1.62.0
# システムの chromium がない場合
python3 -m playwright install chromium
python3 NC_analyzer/tests/test_analysis_workspace.py
python3 NC_analyzer/tests/test_image_copy.py
```

`test_analysis_workspace.py` は固定バージョンのReact・Babel・lucide-react・Tailwind・Chart.jsを `cdn.jsdelivr.net` から取得し、実際のJSXをブラウザーで実行します。生成したWAVの復号と自動解析、変更した範囲だけの再計算、校正変更の自動反映、範囲ドラッグ、並び替えと一括操作、表のドラッグ・Shift / Ctrl選択、グループ一括割り当て、TSVコピー・貼り付け、グループ比較、音量と表示調整、NCA新旧形式の読み込みと追加、ZIP/WAVの内容、実際の `index.html` へのプロジェクト読込、狭い画面での表示を検証します。ファイル選択ダイアログ・保存先ハンドルの境界だけは模擬し、生成されたNCAの実データと書き込み・権限エラー時の動作を確認します。
